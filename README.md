# bonsai-club

Small tools for running a bonsai club.

| Project | What it does |
|---------|--------------|
| [show-votes](show-votes/) | Web app for voting on which trees go in a club show - live D/M/N voting, host include/exclude, comments, CSV + PDF export. |
| [bonsai-ruler](bonsai-ruler/) | Printable ruler that adds dimension context to bonsai photos. |

Each project has its own README. No shared dependencies - pick the one you need.
